## 路线 A · 人机协作版（实时建议器）概览

- **目标**：构建一个轻量的实时牌局建议器，为人工决策提供参考（动作概率、EV 提示、口头解释）。当前迭代仅铺设底层：动作规则、合法掩码、状态契约、自测脚本与文档。训练、神经网络与推理服务将在后续里程碑逐步补齐。
- **本轮交付要点**：
  1. 扩充动作集至 `fold/call/r33/r66/r100/allin`，落地 pot-size raise（r100）与最小加注规则；
  2. `HeadsUpPokerEnv` 输出实时 `to_call / min_raise_to / max_raise_to / legal_mask`，并确保顺序契合“BTN 翻牌后先手”的需求；
  3. 形成稳定 JSON 契约，描述建议器输入状态与输出结果；
  4. 提供自测脚本（smoke / walk / evaluator / r100）方便在无模型依赖的情况下复现与验收；
  5. 补全动作与引擎文档，供后续模块（编码器、serve 层）复用。
- **边界外**：本轮不引入 torch/训练循环，也不实现真实推理服务，仅保证环境与契约稳定，为“人机协作版”后续上线做准备。

> 下一步规划（不在本次交付）将在 `features/encoder.md` 与 `serve/advisor_api.md` 中继续沉淀，包括状态向量设计、CLI/REST 协议以及启发式建议逻辑。
